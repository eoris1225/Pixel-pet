# Pixel Pet

> 작업 규칙·진행 방식·코드 지도는 [`CLAUDE.md`](CLAUDE.md)에 있어요 (새 세션은 거기부터).

다마고치 + 학습 도움 웹앱. 공부한 시간만큼 캐릭터가 레벨 업하고, 레벨마다 아이템을 얻어요.

## 실행

빌드 과정 없이 정적 파일만으로 동작해요. 로컬 서버로 `app/`을 열면 됩니다.

```sh
python3 -m http.server 8000 --directory app
# http://localhost:8000
```

- 하늘은 기기의 현지 시각을 따라 바뀌어요. 다른 시간대를 미리 보려면 `?hour=18.5`, 빨리 감기는 `?speed=600` (예: `http://localhost:8000/?hour=5.5&speed=600`). 계절은 `?season=winter`(spring, summer, autumn)로 미리 봐요.
- 데이터는 이 브라우저의 localStorage(`pixelpet.study.v1`)에 저장돼요.
- 모든 화면(도형·외곽선·아이콘·스프라이트)은 게임과 같은 180×320 픽셀 격자 위에 있고, 화면 크기에 맞춰 정수 배율로만 키워요. 한글 텍스트만 예외로 화면 해상도(실제 픽셀)에서 그려요.
- 서체: PF스타더스트 Bold가 앱의 목소리(버튼·제목·카드·보통 대사)이고, 나머지는 한 가지 일씩만 해요 (`app/css/style.css` 맨 위 표 참고). 갈무리11은 보조 정보와 사용자가 쓴 글(할 일, 메모, 입력칸), 갈무리9는 가장 작은 꼬리표, 갈무리11 Bold는 작은 숫자, 갈무리11 Condensed는 좁은 칸의 이름, 갈무리14는 캐릭터 첫 소개, 물마루는 과목 칩, Silver는 구름 대사. 대사 온도: 람체(조용) → PF Bold(보통) → PF S ExtraBold(들뜸) → 픽셀로보로보(포인트).
- 폰트는 woff2로 서브셋했어요. 픽셀로보로보와 PF스타더스트 S는 일부 글자 조각을 `.notdef`에서 가져오므로 서브셋할 때 `--notdef-outline`이 꼭 필요해요.

| 경로 | 내용 |
| --- | --- |
| `app/index.html` | 화면 뼈대 (월드 캔버스, HUD, 사이드 탭, 시작/휴식/끝, 각 화면) |
| `app/test.html`, `app/js/test.js` | 아이템 테스트 페이지: 세 친구 모두 Lv.10, 아이템 착용/해제·캐릭터 전환·모든 동작 실행 패널 (`/test.html`로 열기, 저장은 따로) |
| `app/css/style.css` | 파스텔 UI 스타일 |
| `app/js/data.js` | **대사·캐릭터 이름·레벨 규칙·아이템 목록·튜토리얼 문구** (여기만 고쳐도 내용이 바뀜) |
| `app/js/sprites.js` | 프로토타입의 픽셀 스프라이트 원본 그대로 (수정 금지) |
| `app/js/pet.js` | 펫 애니메이션·행동 (프로토타입에서 이식), 바닥에 놓인 물건(곰인형·무기·기타·자격증) 상태 |
| `app/js/strum.js` | 하와 기타 연주 프레임 (생성 파일) |
| `app/js/held.js` | 집어 들었을 때 포즈 (빨래집게 그림 트레이싱) |
| `app/js/items.js` | 레벨 아이템 픽셀 아트 (스프라이트 위/뒤에 따로 그림) |
| `app/js/scene.js` | 하늘·해·달(실제 위상)·별·구름·새·참새·나비·반딧불·언덕·숲·큰 나무·소나무·풀밭·나무 표지판 시계. 하늘·구름·땅·나무 색은 계절(봄·여름·가을·겨울)과 시간에 따라 레퍼런스 팩 색을 그대로 써요. 바람에 나무와 풀이 흔들리고, 눈밭엔 발자국이 남고, 캐릭터도 하늘빛을 받아요 |
| `app/js/weather.js` | 날씨: 흐린 하늘·회색 구름·비·천둥번개·눈 쌓임·안개·무지개. 게임 날씨(계절·시간) 또는 실제 날씨(설정) |
| `app/js/app.js` | 상태 저장, 타이머, 레벨/버닝 계산, 투두, 통계, 설정, 인벤토리, 칭호, 튜토리얼 |
| `app/studio/` | Pixel Pet Studio: 모션 프레임 픽셀 에디터 + 아이템 자동 배치 확인·보정 (`/studio/`로 열기) |
| `app/js/item-auto.js` | 프레임마다 얼굴을 찾아 아이템을 붙이는 코드 (게임과 스튜디오가 같이 씀) |
| `app/js/item-fix.js` | 스튜디오에서 보정한 프레임별 아이템 위치 (`설정 복사` 결과를 여기에) |
| `prototype/` | 원본 게임 프로토타입(`pixel-pet.html`) |

## 규칙 (기획 반영)

- 캐릭터: 치카(=모치, 분홍) · 하와(=소라, 하늘) · 욱(=노리, 노랑)
- 순공 60분 = 1레벨, 버닝 시간(18시~0시)에는 50분 = 1레벨. 30분 공부 시 일반 0.5레벨, 버닝 0.6레벨(30/50). 최대 10레벨.
- 짝수 레벨(2·4·6·8·10)마다 아이템 해금, 인벤토리에서 탈부착.
- 칭호 10개(첫걸음, 스타일리스트, 중독 주의, 쉽네, 작심삼일 극복, 새벽러, 깨달은자, 수집왕, 파이어맨, 던전마스터). 조건은 `data.js`의 `TITLES`. 설정의 칭호 메뉴는 첫걸음을 얻으면 열리고, 얻은 칭호 하나를 달면 HUD 레벨 옆에 보여요.
- 시작은 과목을 골라야 가능, 휴식은 타이머 일시정지(펫이 잠듦), 끝을 누르면 기록 여부와 한 일을 작성. 기록 안 하면 그 시간과 경험치는 사라짐.
- 캐릭터를 바꿔도 기존 데이터(기록·다른 캐릭터 레벨)는 유지, 새 캐릭터는 1레벨부터.
- 목표 순공 시간은 임시 기능(통계에 달성률 표시).
